# KortexGPL (Kortex Game Physics Lib)

​Um motor de física em C puro, de alto desempenho, ultra-leve e sem dependências, projetado do zero para desenvolvedores independentes e jogos mobile que exigem eficiência cirúrgica e uso mínimo de recursos.

​🚀 Principais Destaques

- ​Tamanho Microscópico: Pegada de binário extremamente enxuta, variando entre 3 KB e 14 KB dependendo da arquitetura.

- Versatilidade Dimensional: Arquitetura flexível capaz de alimentar desde jogos arcade 2D de alta precisão até ambientes tridimensionais complexos.

- Tri-Arquitetural (Multi-ABI): Suporte nativo otimizado para as arquiteturas modernas mais importantes do mercado:
* ​armeabi-v7a (ARM32)
* ​arm64-v8a (ARM64)
​* x86_64

- ​Zero Dependências: Escrito estritamente em C padrão, sem inchaço de código (bloatware) ou frameworks pesados. Direto ao metal.

​📦 Estrutura de Distribuição

​O projeto é distribuído de forma modular para atender tanto a desenvolvedores que desejam auditar e compilar o código do zero quanto aqueles que buscam integração imediata:

- kortex_gpl_src.zip: Pacote exclusivo com o código-fonte puro e cabeçalhos (include/ e src/).

- ​kortex_gpl.zip: Pacote completo contendo a biblioteca compilada e todos os arquivos de objeto (.o), garantindo transparência total e agilidade na integração.

​🛠️ Automação e CI/CD

​O projeto conta com pipelines automatizados via GitHub Actions para compilação multiplataforma, assegurando estabilidade, padronização e entregas contínuas a cada nova versão.
